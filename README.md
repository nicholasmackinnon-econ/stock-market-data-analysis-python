# Stock Market Data Analysis (Python)

## Overview
This project analyzes historical stock market data using Python.
The analysis compares stock performance, cumulative returns, and volatility
for major technology companies and the S&P 500.

## Tools

## Analysis Performed
Download historical stock prices  
Calculate daily returns
